HOW A ROW BECOMES AN ACTION

Four stages, no glue code.

Connect once, and SheetFlow reads your sheet's own headings as the schema — nothing to configure twice.

01 connect

Link the sheet

Sign in with Google, pick a spreadsheet and a tab. Tokens are encrypted at rest — SheetFlow never sees your password.

02 map

Columns become variables

Headings like Name or Amount turn into {{Name}} automatically — usable in any message or request.

03 configure

Set the trigger and action

Pick a schedule or a row condition, then choose what happens: a WhatsApp message, a webhook, an HTTP call.

04 run

Sheet updates itself

The worker executes the row's job and writes the result — Sent, Failed, timestamp — right back into the sheet.

SYSTEM ARCHITECTURE

Sheet-in, action-out — with a queue in between.

A scheduler never runs the job itself; it hands rows to a queue so retries, concurrency, and failures stay contained.
